# 修士論文プロジェクト

再エネ（太陽光・風力）の拡大による電力価格ボラティリティの増大と、系統用蓄電池の普及によるボラティリティの低減が釣り合う市場均衡点を、JEPX北海道エリアプライスを対象に金融工学的手法で分析し、それぞれの均衡普及量を推定する研究。

## 構成

- [`research-plan.md`](research-plan.md) — **研究計画書本体**。リサーチクエスチョン、先行研究、方法論（3段構成）、データ計画、スケジュール、リスク、代替テーマ評価まで
- `notes/` — 計画書の根拠となった調査ノート（2026年7月時点のWeb調査。要確認事項は計画書§12参照）
  - `01-jepx-market.md` — JEPX市場構造（スポット・時間前・EPRX・容量市場・FIT/FIP・価格史）
  - `02-hokkaido-grid.md` — 北海道電力システム（再エネ導入量・出力制御・北本連系線・蓄電池プロジェクト）
  - `03-literature-renewables-volatility.md` — 先行研究: 再エネと価格・ボラティリティ
  - `04-literature-storage-equilibrium.md` — 先行研究: 蓄電池と市場均衡・カニバリゼーション
  - `05-methods-financial-engineering.md` — 手法カタログ（価格モデル・ボラモデル・均衡モデル・実現可能性評価）
  - `06-data-sources.md` — データ入手可能性（提供元URL・粒度・期間・費用）
  - `07-alternative-research-questions.md` — 代替リサーチクエスチョン8案の詳細評価
