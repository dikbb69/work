## raw/jepx/ — JEPXスポット市場 約定結果

- 出所: JEPX「市場情報 > スポット市場 > 取引結果」 https://www.jepx.jp/electricpower/market-data/spot/
- 取得: 2026年7月26日、本人がブラウザで手動ダウンロード（サイトは自動取得を拒否）
- ファイル: `spot_summary_2016.csv` 〜 `spot_summary_2026.csv`（年度別、11本、cp932）
- 粒度・列: 30分48コマ。受渡日・時刻コード・売り/買い入札量・約定総量・システムプライス・9エリアプライス・ブロック入札4列（計19列）

### 検証結果（2026年7月26日実施）

- 全年度で 行数 = 日数×48 が一致（FY2019・FY2023は366日）。時系列の欠落なし
- FY2026は 2026/4/1〜2026/7/27受渡分まで（取得日時点の最新）
- 九州・北海道エリアプライスに空欄なし。値域の健全性確認済み（例: 九州 FY2016 min=1.49円・0.01円コマ0回 → FY2020 min=0.01円・867コマ → FY2024 1,167コマ。下限張り付きの増加傾向がデータで確認できる）
- 未取得: FY2012〜2015（分析始点を2016年度とする方針のため不要。必要になれば追加取得）

## raw/kyushu/ — 九州エリア需給実績（九州電力送配電）

- 出所: 九州電力送配電「エリア需給実績」公表ページ
- 取得: 2026年7月26日、本人がブラウザで手動ダウンロード
- ファイル: 2形式の混在（計61本、cp932）
  - **旧形式（四半期・60分値）**: `area_jyukyu_jisseki_{H28..H30, 2019..2023}_{1Q..4Q}.csv`（32本）。期間 2016/4/1〜2024/3/31。列: DATE_TIME・エリア需要・原子力・火力・水力・地熱・バイオマス・太陽光実績・**太陽光抑制量**・風力実績・**風力抑制量**・揚水（等）・連系線。単位 MWh
  - **新形式（月次・30分値）**: `eria_jukyu_YYYYMM_09.csv`（202403〜202607、29本）。列: DATE・TIME・エリア需要・原子力・**火力4分類（LNG/石炭/石油/その他）**・水力・地熱・バイオマス・太陽光発電実績・太陽光出力制御量・風力発電実績・風力出力制御量・揚水・**蓄電池**・連系線・その他・合計。単位 **MW平均**

### 検証結果（2026年7月26日実施）

- 四半期32本すべて 行数 = 日数×24、時刻連続（60分間隔）、主要列に欠損なし
- 月次29本すべて 行数 = 日数×48（202607のみ取得日 2026/7/26 19:30 までの部分月）
- **出力制御量（抑制量）列が全期間に含まれる** → 出力制御データを別途取得する必要なし
- 期間カバレッジ: 2016/4/1〜2026/7/26 で欠落なし（202403 は旧形式2023_4Qの2024年1〜3月と重複 → **重複期間は新形式を正とする**）

### 利用上の注意（パイプライン設計で吸収する断層）

1. **粒度の断層**: 2024年2月まで60分値／2024年3月から30分値。長期比較は60分に集計して統一（JEPX 30分値も60分平均に集約して結合）。30分解像度の分析は2024年3月以降のみ
2. **単位の断層**: 旧=MWh（時間電力量）／新=MW平均（コマ平均出力）。新形式は MW平均 × 0.5h = MWh に換算して接続
3. **火力の内訳**: 旧は火力合計のみ。長期系列は「火力合計」に統一（新形式は4分類を合算）
4. **列名の揺れ**: 「揚水」⇔「揚水等」、新形式で「蓄電池」列が新設（旧期間はゼロ扱いではなく欠測扱いとする）
