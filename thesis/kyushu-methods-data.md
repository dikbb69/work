## 1. 共通前処理（`analysis/01_build_panel.py`）

| 処理 | 内容 |
|---|---|
| 文字コード | 全ファイル cp932 で読込 |
| JEPX整形 | 受渡日＋時刻コード（1〜48）→ タイムスタンプ（コマ開始時刻）。使用列: 九州/北海道/東北/システムプライス・売買入札量・約定総量 |
| 需給実績（旧形式） | 60分値・MWh。列: 需要・原子力・火力・水力・地熱・バイオ・太陽光実績/抑制量・風力実績/抑制量・揚水・連系線。2024年3月分は新形式と重複のため除外 |
| 需給実績（新形式） | 30分値・**MW平均**。時刻ラベルはコマ終端（0:30＝0:00-0:30）→開始時刻に変換。日付は `20240401` 型と `2025/12/1` 型の混在に対応。火力4分類は合算列 thermal を作成 |
| 粒度・単位の統一 | 長期パネルは**60分**に統一：JEPX30分→2コマ平均、新形式30分MW平均→時間平均（ランク・比較用途。エネルギー量が必要な場合は×0.5hでMWh化） |
| 会計年度 | FY = 4月〜翌3月。FY2026は部分年度（価格は2026/7/27受渡分・需給実績は2026/7/26まで）のため年度間比較から除外 |
| 品質確認 | 全ファイルで行数=日数×コマ数、時系列連続、主要列欠損ゼロ、価格結合後の欠損ゼロを確認（`data/README.md`） |

**出力ファイルと主な列**

- `jepx_kyushu_30min.csv`: ts, koma, p_kyushu, p_system, p_hokkaido, p_tohoku, 売買入札量, 約定総量, fy
- `kyushu_hourly_panel.csv`: ts, demand, nuclear, thermal, hydro, geothermal, biomass, solar, solar_curt, wind, wind_curt, pumped, battery(2024/3〜), interconn, p_kyushu ほか, fy
- `kyushu_daily_metrics.csv`: day, p_mean/min/max, floor_koma(≤0.011円), spike50/100_koma, spread_maxmin, **spread_tb4h**, 需要・太陽光・風力の日量, 制御量日量, **curtail_day**, fy

## 3. 案1: 蓄電池バックテスト（`03_battery_backtest.py`、図f7）

**共通仕様**: 出力1MW・4MWh（4時間）・往復効率η=0.85（放電収入に一括適用）・1日1サイクル・SoC持ち越しなし・劣化無視・価格テイカー・スポット裁定のみ。**全戦略60分粒度**（30分価格の時間平均）で統一し、比較可能性を優先。

**日次粗利（円/MW-日）**: 放電4時間の集合 T、充電4時間の集合 B に対し
`m = η·Σ_{h∈T} P_h·1000 − Σ_{h∈B} P_h·1000`

| 戦略 | 情報集合（受渡日Dの充放電帯決定に使える情報） | T・Bの決め方 | 負値の扱い |
|---|---|---|---|
| 完全予見 | 当日Dの実現価格（事後） | 当日価格の上位/下位4時間 | 0に切り上げ（休止オプション） |
| a. 前日価格 | 受渡日D-1の実現価格（D-1昼に判明済み） | D-1の価格ランクをDに適用 | そのまま（コミット済みとみなす） |
| b. 前日予測 | **D-2までの需給実績のみ**（TSO計画値のアーカイブ非公開のため情報集合を代理再現） | 需要予測（平日/休日別・直近28日の同時刻平均）−太陽光予測（直近7日の同時刻平均）＝予測残余需要の下位4時間に充電・上位4時間に放電 | 同上 |

- 年度集計: 円/kW-年 = Σ日次粗利/1000。捕捉率 = 戦略値/完全予見
- ウォームアップ: 先頭30日はbの予測窓が揃わないため除外（aは先頭1日）

## 4. 案2: モンテカルロ（`04_spread_montecarlo.py`、図f8）

- **対象系列**: 完全予見の日次粗利 m_d（円/MW-日、03の出力）
- **モデル**: m_d = s(month) + x_d、x_d = ρ·x_{d−1} + ε_d
  - s(month): 月別平均（季節成分）。ρ: 残差のAR(1)係数（OLS）
  - ε: 残差の**経験分布からのiidブートストラップ**（正規性等の分布仮定なし）
- **シミュレーション**: 5,000パス×365日。日次値は max(0, s+x) に切り上げ（休止オプション）。年間値=Σ/1000（円/kW-年）
- **推定窓**: 主=FY2023-25（燃料正常化後の現行構造）／感応度=FY2021-25（危機込み）
- **検証**: 実現年間値（FY2023-25）をシミュレーション分布と比較 → 年度間変動を過小評価（第2報§2.3。年単位の持続要因が未モデル化のため。HAR型・燃料価格状態変数・レジームが本番の改善課題）

## 5. 規格化指標（`05_normalized_metrics.py`、図f9〜f10）

価格「水準」（燃料価格）に比例して膨らむ効果を除き、**形状（太陽光による日内構造）由来**の裁定機会を測る。

| 指標 | 定義 | 単位 |
|---|---|---|
| 相対スプレッド RS_d | TB4hスプレッド_d ÷ **当日48コマ平均価格**（当日平均をベース＝フラット価格とみなす） | 無次元 |
| 等価時間 EH_fy | 年間裁定粗利（円/kW-年）÷ **年度平均価格**（円/kWh）＝「平均価格の電気の何kWh分を稼いだか」 | kWh/kW-年 |

- 参考: 年間放電量は最大で約1,241kWh/kW-年（365日×4h×0.85）。充放電の価格差が平均価格を上回る年はEHがこれを超えうる
- ベースの選び方の代替案（本番での感応度候補）: システムプライスで除す（エリア固有要因の分離）、燃料指数で除す（燃料効果の直接統制）、前年度平均で除す（同時性の回避）

## 6. 既知の限界一覧（すべて意図的な簡略化。本番での扱いを併記）

| 限界 | 本番（北海道）での扱い |
|---|---|
| 劣化無視 | Xu et al. (2016) 工学モデル＋知覚効率ヒューリスティック（Butters流） |
| 1日1サイクル・4h固定 | SoC連続の動的計画法・duration選択の内生化 |
| 価格テイカー（自分の充放電が価格に影響しない） | 価格インパクトの内生化（残余需要シフト＋供給曲線） |
| スポットのみ | 需給調整市場・容量市場収益のスタッキング |
| 60分粒度 | 30分コマ粒度（2024年3月以降＋JEPXは全期間30分） |
| 太陽光導入量が実績最大の代理 | METI系統WG・FIT公表の公式接続量系列に置換 |
| 年単位の持続要因が未モデル化（案2） | HAR型長期記憶・燃料価格状態変数・レジームスイッチング |
