# フェーズC v1: π(K)曲線と均衡容量K*の初回判定 — 結果メモ

- 作成日: 2026年9月29日
- スクリプト: `analysis/23_pi_k_curve.py` → `figures/hokkaido/pi_k_curve.png`・`data/processed/pi_k_curve.csv`
- 位置づけ: 主線フェーズC（蓄電池フリートの内生化）の初回実装。8/17ゼミの工程どおり

## 1. 手法（v1）

- 価格過程v1・仕様A（決定論: p=g(net;季節)+μ(季節,時刻)）の上で、蓄電池フリートを
  **10万kW刻みの増分貪欲ディスパッチ**で逐次投入（各増分はその時点の価格で最安4h充電・
  最高4h放電、正マージンの日のみ稼働）→ 「各参入者が残されたスプレッドを順に取る」
  競争均衡の近似。net と価格を増分ごとに更新
- π_spot(K) ＝ フリートK投入後の価格での限界参入者（価格テイカー・完全予見4h）の年間裁定粗利
- 実現可能収益 ＝ π_spot(K)×capture 0.81（気候値戦略c実測）− 充電従量負担1.2円/kWh（年1,752円）
- 参入条件: π_実現可能(K) ≥ c_req − κ·P_cap ＝ 2.20万円/kW-年（標準）／1.95万（楽観）／2.87万（保守）
- 実装教訓: 1パス（窓を変形前価格で固定）だと大Kでフリートが安値時間を高値に「反転」させ
  π(K)が偽の上昇をする。増分化で単調減衰に修正済み

## 2. 結果: π(K)曲線（FY2023-25パス平均、円/kW-年）

| K（万kW・4h） | 現状 π_実現可能 | 泊3号再稼働 | 泊＋風力2倍 |
|---|---|---|---|
| 0 | 4,944 | 5,480 | 5,847 |
| 25 | 2,437 | 3,047 | 3,587 |
| 50 | 1,075 | 1,801 | 2,358 |
| 100 | −953 | −339 | +231 |
| 150〜300 | ≈−1,600（飽和） | ≈−1,500 | ≈−1,000 |

- **カニバリゼーションは速い**: K=50万kWでπは半減以下、K≈100万kWでスポット原資はほぼ枯渇
  （ERCOTの「2年で1/6」と整合的な速度感）。泊・風力2倍でも飽和点は100〜120万kW程度しか動かない

## 3. 判定: 純市場の均衡容量 K* ＝ 0（全シナリオ・全ケース）

- π_実現可能(0)＝4,900〜5,800円/kW-年 ＜ 参入必要水準19,500〜28,700円 → **K*_merchant＝0**
- 8/17時点の「収入スタック2.25万 vs c_req 3.2〜3.7万」の粗い比較が、フリート内生化後の
  モデルでも維持された。**2枝設計の枝B（政策による過剰参入）が定量的にも確定的**:
  - 現実の道内パイプライン（契約申込234万kW）は、モデルのスポット飽和点（約100万kW）すら大きく超過
  - 参入はLTDA・補助金・容量市場・価格期待（政策層）で説明する構図が本線になる
- **損益分岐AFC**: K=0で参入が立つAFC(4h)は約1.05〜1.14万円/kW-年 ＝ 資本費換算で
  **約1.5万円/kWh（現行実勢6.8万円/kWh の2割強）**。蓄電池産業戦略の長期目標
  （揚水並み2.3万円/kWh）まで下がっても、現行の価格構造・容量市場価格の下では純市場参入は開かない

## 4. 重大な留保（結論の一次感度）

1. **価格過程がFY2026型の高スプレッドを過小評価**（OOSでTB4h実績18.7円 vs モデル10円前後）。
   FY2026水準が定常化しているなら π は約2倍あり得、損益分岐が大きく動く
   → **供給曲線v2（構造スタック＋マークアップ校正）が結論の一次感度**。次の最優先
2. 容量市場収入をK不変で扱った（P_cap(K)のカニバリ未実装）。実装すれば必要水準が上がり
   K*=0の結論は強まる方向
3. 仕様A採用（裾圧縮で保守側）・1日1サイクル・EPRXゼロレント・BTM価値（ローカル抑制回避）除外
4. 政策層ストック（LTDA道内43.7万kW〜＋FIP併設）を初期投入していない。投入すると
   マーチャントの残余原資はさらに薄い → 同じく結論を強める方向

## 5. 次のステップ（自律実行可能な順）

1. **供給曲線v2**: 年効果／燃料指数でgの上側を非定常化 → FY2026再現 → π(K)再計算（留保1の解消）
2. **K_wind×K格子**: 同じ機構で2次元サーフェス（風力導入量×蓄電池容量）
3. **P_cap(K)の実装**: 公表需要曲線＋道内ブロックの閉形式で容量側カニバリを内生化
4. **BTM B-1/B-2**: 抑制イベント分解・0.64kWh/kW制約下の回避可能率
5. break-evenフロンティア: 「AFC×容量価格×スプレッド水準」でK*>0となる連言条件の曲面
