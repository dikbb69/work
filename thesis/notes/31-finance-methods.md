# 31. ファイナンス手法の棚卸しと追加候補（2026-10-20）

担当教員のコメント「ファイナンス（金融工学の手法）の使用と成果について、もっと明確に触れた方が良い」への対応の検討記録。棚卸し3・候補4レンズ・敵対的レビュー4の計11エージェントで行った。パイロットはレビュー側で全て再実行して数値の再現を確認した（スクリプトと全出力: `analysis/pilots/finance_20261020/`）。

## 0. 結論

1. **原稿はファイナンスの手法を既にかなり使っているが、それをファイナンスの言葉で書いていない**。原稿に「ファイナンス」「金融工学」という語は一度も出てこない。完全予見バックテスト、capture率、ゼロレント条件、c_req、θ*、LTDA の還付などは、それぞれ標準的なファイナンスの概念に対応する（§1）。まず「本研究のファイナンス上の位置づけ」節と対応表を置き、各章の記述を言い換える。追加計算は要らない。
2. **追加する価値のある手法は6〜7本**。どれも工数1〜3.5日で、結論（K*=0）を強める方向に働く（§2）。最優先は、実物オプションによる動学的参入閾値、24時間価格カーブの主成分分解、日次スプレッドオプションの層分解、マーチャント IRR と LTDA の IRR の対比、の4本。
3. **検討の過程で、原稿の誤りが4点見つかった**（§3）。とくに「風力が価値を作るのは下限での打ち切り」という機構の説明（11.3 ほか）は論理が逆向きで、検算でも確認した。ファイナンス手法の追加とは関係なく、直す必要がある。

## 2. 未使用手法の検討（レビュー後の判定。数値は修正後）

### A：採用を推奨

**A1. 実物オプションによる動学的参入閾値**（Dixit-Pindyck 第8章の競争産業均衡、Schwartz-Smith 型2因子＋カルマンフィルタ、Broadie-Glasserman-Kou の離散補正、反射壁モンテカルロでの検算）。工数3.5日。
- 競争均衡でも参入閾値は静学の β/(β−1) 倍に上がる。競争が消すのは参入時の超過 NPV で、閾値の上乗せは消えない。したがって原稿の静学ゼロレント条件は動学閾値の下限であり、静学の K* は上限になる。K*=0 はより強く成り立つ。
- 必要な θ は 3.2〜4.6 から、σ=0.10〜0.30・資本費一定で約4.8〜7.4 に上がる。資本費が年5%下がる見込みなら、不確実性がなくても使用者費用 (r+g)/r で閾値は約1.8倍になり、これは競争でも消えない待機の理由になる（「時間遅れの普及」の理論的根拠）。
- FY2026上期の θ≈1.55 は、恒久成分1.21 × 一時成分1.28 に分解される。2040年度までにマーチャント参入が開く確率は、動学で σ=0.30 でも2.5〜5%、σ=0.11 なら0.2%以下（静学では11〜27%）。
- 限界: 恒久成分の σ は識別できない（2016-04〜2021-03 は0、2023-04 以降は0.11、燃料危機を含む全期間で0.30）。σ は幅で示す。実物確率と WACC で割り引き、リスク中立化はしない（北海道に先物がない）。Helios（札幌、100%マーチャント、2025年12月運開）を反例として本文で扱う必要がある。

**A2. 24時間価格カーブの主成分分解と因子エクスポージャー**（Litterman & Scheinkman 1991 の水準・傾き・曲率の類比。24時間は同一オークションで決まる受渡時刻別の商品なので、短い期間構造とみなせる）。工数2.5日。
- 第1主成分（水準）が年度・季節内の日々の変動の78%（FY2023〜25 は57%）、第2主成分（昼が負・夕方が正のダック因子）が7%（同17%）。
- 風力の時刻別係数はほぼ一様（FY2016〜25 の冬は比例シフト b=λ·p̄ を棄却できず、p=0.09〜0.15）。夕方−昼の差はどの季節でも広げない。太陽光は夕方−昼の差を +0.4〜0.6円/kWh per GWh/日 広げ（p≤0.003）、FY2023〜25 では冬も広げる。
- 風力の日間変動を3倍にしても完全予見粗利は ±3%しか動かない。太陽光を3倍にすると +5〜13%。完全予見粗利 = 0.80·PC1 + 1.20·PC2 − 1.33·PC3（R²=0.91）。蓄電池は「水準と形状のロング・ポジション」であり、風力は水準因子、太陽光は形状因子を通じて価値を動かす。この言い方で第6章と第7・8章を一本につなげられる。
- 修正点: 「風力は一日を平行に沈める」は厳密には棄却される（23制約の Wald で p≤0.002、5制約への縮約版とブロック・ブートストラップでも p≤0.013）。「ほぼ一様に（冬は比例的に）沈め、昼と夕方の差は変えない」と書く。冬の安値時間は夜なので、夕方−夜の差も併記する（風力は冬に −0.35***、不需要期に −0.21*** でこれを縮める）。
- ゼミ指摘3（価格モデルのカーブと感応度を見せる）と同じ図にまとめられる。

**A3. 日次スプレッドオプションの層分解**（intrinsic／休止／完全情報の価値）。工数1.5日（ほぼ計算済み）。
- FY2023〜25 の完全予見粗利 10,317 = intrinsic 8,427（81.7%） + 休止 208（2.0%） + 完全情報の価値 1,682（16.3%）円/kW-年。capture率0.81 は intrinsic の比率そのもの。冬は intrinsic 比が0.61、完全情報の価値が31% と大きい。
- (III) は「前日約定後に組み替えた場合の上限」で、ガス貯蔵の extrinsic（フォワードの動的取引で実際に得る価値）とは性質が違う。「完全情報の価値」と呼ぶ。Bachelier 近似は時間価値を約6倍過大に出すので使わない。
- 完全予見粗利は「ペナルティなしの情報緩和による上界」（Brown, Smith & Sun 2010）として位置づけられる。2〜3文で書ける。

**A4. マーチャント IRR と LTDA の IRR の対比、資産の資本コスト r_A、確実性等価**。工数1〜1.5日。
- マーチャント4h の事業 IRR（無レバレッジ・税前・20年）は、モデル値で −7.7%、×1.25 上限ケースで −5.7%、FY2026上期水準×1.25 でも −1.4%。割引率をいくらにしても K*=0 は変わらない。
- LTDA 上限価格7.2万円の IRR は、契約容量＝期待容量（κ=0.932）なら12.3%、設備容量なら13.7%（契約容量の定義は募集要綱で要確認）。
- θ* を r_A 別に出すと、5%で3.49、6%で3.77、8%で4.35、9%で4.66。原稿の6%は契約型の水準（LTDA の事業報酬率4〜6%、FIT の IRR 6%）にあたる。マーチャントは r_A 8〜9% と位置づけ直す（想定問答 #12 への答え）。
- LTDA の価値のうち86%以上は期待値の移転で、リスク移転（保険価値）は14%以下（期ごとの CAPM 調整で計算。λ・ρ は仮定）。
- 注意: 「レバレッジでエクイティ IRR が上がるから応札が超過する」という論法は MM 命題に反するので使わない。

**A5. 予測評価と取引ルールの検定**（Diebold-Mariano、White 2000 の Reality Check／Hansen 2005 の SPA、Diebold & Li 2006 の動的因子予測）。工数1日。
- c−b は +289円/kW-年（DM 4.1）、c−a は +1,361円（DM 12.3）、a2−a は有意でない。Diebold-Li 型の1・3・5因子予測は、いずれも気候値 c に負ける（−0.8〜−2.2ポイント、DM −2.4〜−4.2）。「期間構造の標準的な予測モデルでも、前日の情報は気候値に勝てない」と書ける。
- c は複数の戦略から事後に選んだので、SPA の形にする。0.81 は「試した戦略の中の最善で、価格条件付き入札の余地を残す保守値」と位置づける。

**A6. 系列相関に頑健な推論**（Newey-West、Kiefer-Vogelsang の fixed-b、Lazarus et al. 2018 の EWC、年月FE 版の頑健性）。工数1日。ファイナンスの手法としてアピールするものではないが、必須。
- 残差の1次自己相関は0.76〜0.92 で、HC3 だけの表6.2 は推論として不十分。
- 風力・冬の TB4h −0.363 は NW で1%有意のまま。年月FE では −0.18**、価格ラグを加えると非有意。FY2023〜25 では全季節で非有意。頑健なのは「風力は TB4h を広げない」で、「冬に縮める」は弱い。
- 太陽光・冬の −0.81 は月FE で −0.12、年月FE で +0.39 と符号が変わる。撤回が必要（§3-3）。

**A7. 多因子 CFaR**（Andrén, Jankensgård & Oxelheim 2005 の exposure-based CFaR）。工数1.5日。
- 日々の天候ノイズは年間で分散され、CV は3〜5%（CFaR05 557円）。ただし年度単位の形状の変動（σ≈0.23）は分散されない。
- 最大のリスク源は他者の参入 K: π(20万kW)=2,972（K=0 から −1,972）、π(57.7万kW)=763（−4,181）で、天候の CFaR の4〜8倍。
- 「年次リスクの主因は θ」は FY2022 の1年に依存する（除くと R² 0.60→0.19）。θ・K・容量価格・年度の形状の4因子で組み直す。

### B：余力があれば

- **ヘッジ有効性と市場の非完備**（Ederington 1979）: 東京のベース先物の代理でヘッジできる分散は、平常時（FY2020〜22 を除く）で2〜3割、FY2023〜26 で5割程度。日内スプレッドの北海道–東京相関は FY2023 0.66→FY2025 0.52 と低下。上場先物のテナーは数年なので、20年の水準リスクはヘッジできない。第11章に半ページ（0.5日）。間接送電権が補完的という主張は根拠が弱いので書かない。
- **接続枠（契約申込）の実物オプション価値**: 申込234万kW と運開の差を、期限と保有コストのある待機オプションとして読む。2026年4月以降の保証金増額（次世代電力系統WG）が外生ショックになる。保証金額の一次資料が前提。
- **GARCH-X（FY2023〜25 に限定）**: ファイナンス計量で最も認知された手法で、原稿は Kyritsis らの GARCH 結果と対比しながら自分では推定していない。「風力は日間を安定させる」が覆るリスクがある。
- **アセットベータの推定**（CAPM、Hamada 1972。上場インフラファンドとマーチャント型事業者の比較）と、**先物の期間構造による恒久成分の識別**（Schwartz-Smith 2000 の本来の推定法、EEX の日本電力先物）。どちらも著者のデータ取得が必要。

## 3. 検討の過程で見つかった原稿の誤り

1. **下限価格の機構の向き（8.2 l.46、10.1、10.6 l.69、11.3 l.25、デッキ c-impl・c-curves）**。11.3 は「風力は価格を平行に下げるが、0.01円以下には下がれない。床に当たると安い側だけが切り取られ…スプレッドが開く」と書く。しかし平行シフトで安い側だけが止まれば、スプレッドは縮む。FY2023〜25 の実績価格を一様に δ 円下げて 0.01 円で打ち切ると、完全予見粗利は δ=0・1・2・3・5・8 で 10,317→10,339→10,316→10,263→10,053→9,259 円/kW-年 と下がる（打ち切らなければ1円あたり +219 で上がる。2026-10-20 に独立に再計算）。第8章のスイープで価値が上がるのは、純需要が下がると安い時間ほど大きく下がる供給曲線の下端の急勾配（20分位ビンの傾きは、下端1.15円/kWh per 100MW、中位0.4〜0.5、上端≈0）による非平行の効果である。下限価格そのものは充電側の値下がりを止め、価値を削る（蓄電池は充電脚でプットを売っている形）。書き直しの順序: 現行水準では風力の効果はほぼ平行で、価値を動かさない → 導入量が増えると低純需要の時間が供給曲線の下端の急勾配域に入り、非平行になってスプレッドが開く → 下限価格はその落ち込みの終点で、それ自体は価値を削る。
2. **Leahy・Grenadier の読み方（2.5 l.69、5.4.3 l.91、9.2(e) l.27）**。「競争下では待機オプションの価値が侵食され、参入は近視眼的な NPV 判断に近づく」「参入ラッシュは期待の先取り競争」は誤読。Leahy の「近視眼的」は、他社の参入を無視しつつ自分の待機オプションは考慮するトリガーを指す。閾値の上乗せは残る。Grenadier (2002) は開ループの Cournot で先取りを含まない。正しくは「静学ゼロレント条件は動学的な参入閾値の下限であり、静学の K* は上限」（A1）。先取り均衡（Fudenberg-Tirole 1985、Weeds 2002）でも静学 NPV<0 の参入は起きない。
3. **HC3 だけの推論と、頑健でない2つの記述（6.2、デッキ em-regression の冬の機構、QA）**。北海道の太陽光が冬に TB4h を縮める（−0.81）、九州の風力が不需要期に TB4h を広げる（+0.275）は、同月内の識別で消えるか反転する。ゼミ指摘1（冬は太陽光・風力ともにスプレッドを縮める）への回答も、太陽光の部分は FY2016〜25 プールの HC3 に依存していたので修正が要る。
4. **細部**: 7.2 l.33「戦略cは全年度で81〜84%と安定」は誤りで、FY2016〜25 は76.4〜84.3%（FY2018 78.4%、FY2019 79.3%、FY2021 76.4%）。表7.3 の冬・風力小は現データで 18.98円/kW-日・TB4h 7.24円（原稿 19.2・7.30）。「ヘアカット」は金融では担保の掛け目を指すので、初出で定義するか「実現率」と言い換える。c_req の起点の不統一（8.4 は3.45万・θ*3.55、9.4 は3.59万・3.76）は HANDOFF の既知の不整合と同じ。
