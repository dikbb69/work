## build の残る問題
(1) 仕様A′ は判定基準（主仕様の全季節・全脚で p>0.10）を満たしたが、有意でないことは一致を意味しない。不需要期の完全予見粗利の差は点推定 +0.35円/kW-日（95%区間 −0.13〜+0.82）で、仕様A の約6割が残る。μ を年度抜き取りで推定すると p=0.09 になる。状態変数（風力・日平均/最小/最大純需要）×分位数（3〜8）×中央値/平均を試して選んだので、選択の偏りがある。中央値版は p=0.07 で基準を満たさない。仕様A′ の風力シナリオも上限側の可能性が残る。また μ は最上位の三分位より先へ外挿しないので、風力3倍の効果は頭打ちの仮定に依存する。
(2) λ は K=0・θ=1 の in-sample 校正である。K>0 で一定とするのは上側になりうる。一方 out-of-sample の 実績c/モデルc は FY2026 4〜6月 1.23、FY2022 1.60 で、K=0 では実績整合も過小の可能性がある（FY2026 は3か月だけ）。
