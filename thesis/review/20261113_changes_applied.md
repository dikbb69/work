## 1. 赤字の付け方

- 書き足した文と、言い回しを変えた文を赤字にした。文の単位で判定している。元の文をそのまま残した箇所は、段落を組み替えた場合も黒のままである。
- 番号を振り直した図表の参照（「表4.4」など）は、番号の部分だけが赤字である。
- **削除だけの箇所は赤字が残らない。** 第3節に一覧を載せた。
- 本文の数式（式4.1〜4.12）は一切触っていない。
- 赤字を黒に戻すには、Word で全選択（Ctrl+A／⌘A）してフォントの色を「自動」にする。

## 2. Word を開いたときの注意

1. 開くと「フィールドを更新しますか」と聞かれる。**「はい」を選ぶ。** 目次・図目次・表目次のページ番号が更新される。聞かれなかった場合は、目次を右クリックして「フィールド更新」→「目次をすべて更新する」。
2. 新しい図2点（図6.1、図6.3）は IPA Pゴシックで描いた。ほかの図は Hiragino Sans なので、書体が少し違う。Mac で次を実行すると同じ書体の図ができるので、Word の図を差し替える。

   ```bash
   FIG_ONLY=1 python analysis/100_v2_review_figures.py
   ```

3. 図4.1 は、画像の中の「表4.2」を「表4.4」に直した（元の画像の数字を写して貼った）。直した画像は `figures/hokkaido/model_flow.png`。画像の中の「比べる3つの場合」という語は直せていない。
4. 表が途中で切れないように、行をまたがない設定と、短い表を1ページに収める設定を入れた。空白が大きくなったページがあれば、表の位置を調整する。
