## S3. 北海道の初期実証(2): 価格構造 — 九州と「量は半分、価値は同等」

- **床コマ（0.01円）は年473コマ ＝ 九州の約半分**。しかし**PF価値（完全予見4h・η=0.85）は
  0.96〜1.15万円/kW-年で九州と同水準**〔h1・h3〕
  - 九州: 床（昼の底）由来の価値 / 北海道: 夕方スパイク（上裾）由来の価値 — **価値の源泉が異なる**
- ダックカーブは形成途上（昼の窪みは九州より浅い）〔h2〕
- **市場分断の方向が逆転**: 高値分断（道内が本州より高い）87〜92% → 直近約60%へ。
  安値分断が1〜5%→約30%に増加 ＝ 余剰の輸出制約が顕在化し始めた〔h5〕
- 含意: 北海道は「九州の後追い」ではなく、風力・スパイク・分断という**別の構造**にある

## S4. 北海道の初期実証(3): 予見可能性と運用戦略

- 実行可能戦略のcapture率（PF比）:

## S5. 北海道の初期実証(4): 風力の構造 — 長周期が支配的

- **風力変動の帯域分解**（フリート集約出力）: 日内（<24h）は小さく、
  **1〜7日帯35.7%＋7日超帯38.6% ＝ 分散の4分の3が「数日〜週」の長周期**〔h6〕
  - 太陽光（6-24h帯が中心）と対照的 → **4h蓄電池の日次シフトでは吸収できない構造**
  - 蓄電池のduration価値・貯蔵技術選択に直結する基礎事実
- **風力の電力量シェア実測10.2〜10.3%**（FY2024-25）: 先行研究がMOEを検出した水準
  （Woo 5-8%、Ketterer 6-8%）を既に超過
- **分位点回帰**（Sakaguchi & Fujii 2021 の再現・延長）: 高分位ほど強い風力MOE
  （τ0.9で−11.2円/kWh/GW、FY2016-19）→ 風力倍増後のFY2023-25は−4〜−7円に**減衰**
  （連系線増強・市場統合の効果と整合）〔h7〕

## S8. 先行研究(3): ギャップと本研究の位置づけ

- **均衡系（系譜D）はすべて太陽光・海外市場**: Butters=CAISO・太陽光、Karaduman=NEM、
  BDG均衡モデルは curtailment・duration選択・連系線分断・マルチマーケット収益を
  「限界」と自ら明記 → **その限界5点が北海道では一次的に重要**（本研究の拡張ポイント）
- **日本の実証（系譜C）は誘導形のみ**: 蓄電池を内生化した均衡分析は見当たらない。
  METI 2030年見通し（14.1〜23.8GWh）も接続申込の外挿であり均衡概念ではない
- **最類似 Fuke & Ohashi (2025) との差別化3点**:
  ①対象: 九州・太陽光・季節性 → **北海道・風力**（高分位MOEの追試で接続済み）
  ②手法: 誘導形の変動性記述 → **構造モデル＋自由参入均衡**
  ③問い: 変動性がどう変わったか → **蓄電池が何GWまで入るのが均衡整合的か（K*）**
- → 空白 ＝ **「北海道×風力×蓄電池の均衡容量」**。ここを埋めるのが本研究

## S9. 今後の方針: 「均衡容量K*」への道筋（実証と文献の帰結）

- **主張の型**（研究計画v2で確定）: 「必然」は使わない。無裁定・均衡整合性命題2つ:
  - 命題1: 現状容量K₀では限界参入者の利潤が非ゼロ → K₀は自由参入均衡でない
  - 命題2: 全シナリオで K* ≥ K_min（**確率なしの頑健下限コリドー**）
  - 二層参入: LTDA・補助＝政策層（外生）／マーチャント層のみゼロ利潤。主結果は純市場ケース
- **均衡条件の部品は実測済み**: π_spot(K) + κ(h)·P_cap(K) − c_req = 0
  - κ(4h)=73→84%・P_cap=公表需要曲線の閉形式・政策層K=LTDA道内43.7万kW〜
  - AFC(4h)=2.5〜3.0万円/kW-年（METI実勢6.8万円/kWh）＋託送等0.69万 → **c_req≈3.2〜3.7万**
- **予備試算の手応え2つ**（価格過程v1: p=g(net;季節)+μ(時刻)、net経由でK_pv・K_wind・泊・DCが変数）:
  1. 現状の純市場収入 約2.25万円/kW-年 ＜ c_req → **足元の参入は政策層駆動の可能性**
     → 「頑健下限」でも「政策による過剰参入」でも論文が立つ2枝設計
  2. 泊3号re稼働 **+1,184** / DC需要+80万kW **−797** / 両方 **−11円/kW-年 ≈ 完全相殺**
     → 構造イベントの相殺ネットの定量化が中心貢献になり得ることを確認
- **工程**: フェーズC（蓄電池フリートをnetに内生化 → π(K)曲線 → K*初回推計）→
  HVDCワーストセルで主張の型のgo/no-go → 前提フリーズ日（2027/3末）宣言

  ヘアカット可能。DP厳密解との乖離も検証済み（−0.3〜−1.7%/年）

  し得る。だからこそ静的な係数でなく構造モデルでK依存性を扱う（S9）

  投稿前に後方引用の系統的検索で再確認する（レビュー文書に明記済み）
- **Q. 泊が蓄電池に有利（+1,184円）は本当か? 火力退出の内生反応は?** → 現段階は退出固定の
  部分均衡。苫東厚真1・2の退出を泊条件付き分岐として次段階で処理
