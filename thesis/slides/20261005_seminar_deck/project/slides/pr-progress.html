前回8月17日のゼミからの進捗です。左の表が時系列、右が前回いただいた討議3点への回答です。8月下旬から9月は、まず π(K) を推計しました。蓄電池の総容量 K が増えたとき、最後に参入する蓄電池が1kWあたり年間いくら稼げるかの曲線です。これが参入に必要な水準と等しくなる容量が均衡容量 K* で、限界参入者の NPV がゼロになる点です。スポット裁定だけのマーチャントでは K*=0 でした。続いて頑健性を固めました。水準係数 θ は価格の水準を年度ごとに伸び縮みさせる係数で、2026年度上期の高い価格を取り込むために入れました。2次元の感応度面は風力の導入量と蓄電池容量を同時に振った計算、損益分岐面は資本費と容量収入の組み合わせごとに参入に必要な価格水準を示したものです。空間分散は風車が広く散らばっていることが結果を作っていないかの確認、燃料危機期の除外は2021〜22年度を抜いた推定です。並行して先行研究56本（コア41本と追加15本）を原典で読み直し、初稿を書きました。この期間は git 上すべて9月29日付で、個々の日付は特定できません。9月30日には、JEPX（日本卸電力取引所）の最低価格0.01円/kWh、つまり価格の下限を主線に格上げして第10章を新設しました。10月4日は季節区分を夏＝7〜9月に変えて再推定し、第9章の LTDA（長期脱炭素電源オークション）、SII（環境共創イニシアチブ）の補助金、OCCTO（電力広域的運営推進機関）による出力制御、つまり再エネの発電を止める措置の検証を一次資料で確認しました。下の囲みのとおり、北海道の風力の夏の TB4h、つまり1日の高い4時間と安い4時間の平均価格差への係数は、9月を含めたことで有意でなくなりましたが負のままで、風力が日内の価格差を広げないという主張は変わりません。前回資料とも数値が違い、夏の風力の多い日の完全予見粗利は、7〜8月だけだった前回の約−2%から+7%になりました。右側の回答です。①は価格が下限の0.01円に届く前の局面として書き分け、②は均衡分析を進めて K*=0 を得、③は4時間から6時間でスポット価値が27%増えることを7.4に残しています。 根拠: HANDOFF §1・§4（10/4 セッション）、git log、原稿 6.2・表6.2・7.3・表7.3・7.4、第8章
